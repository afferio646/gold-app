# Goldmorr Admin Dashboard Setup

## Live Deployment
The dashboard is live at: `https://gold-app-two.vercel.app/dashboard.html`

## Admin Access
- **QR Code:** The `qrcode_admin.png` points to `admin.html` (The Goldmorr Admin Hub).
- **Direct Link:** `https://gold-app-two.vercel.app/admin.html`
- **Dashboard Direct:** `https://gold-app-two.vercel.app/dashboard.html`

## Troubleshooting
If you see the old login screen:
1. Close the app.
2. Re-scan the QR code.
3. Look for the green **v2.0 LIVE** badge in the header.

## QR Codes
All QR codes generated (`qrcode_randy.png`, `qrcode_brett.png`, `qrcode_admin.png`) are **static**. They point to the filenames (`facility.html`, `admin.html`), which do not change. You do not need to reprint them when we update the code.
