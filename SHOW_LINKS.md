# Goldmorr Show Links - Desktop Usage Guide

These links are optimized for desktop use. You can open them on any computer at the show.

## 1. ADMIN HUB (Start Here)
Use this link to launch either the Facility Tool or Member Suite from a central menu.
👉 **Link:** `https://gold-app-two.vercel.app/admin.html`

## 2. CLIENT DASHBOARD (Data & Tracking)
Use this link to view live leads, export CSVs, and reset the system.
👉 **Link:** `https://gold-app-two.vercel.app/dashboard.html`

## 3. PUBLIC FACILITY TOOL (Testing User Flow)
Use this link to simulate what a Facility Manager sees (scan QR code flow).
👉 **Link:** `https://gold-app-two.vercel.app/facility.html`

---

### Tips for Desktop Use:
- **Bookmark these links** in your browser (Chrome/Edge recommended).
- The dashboard is fully responsive and will look great on a laptop screen.
- You can keep the dashboard open in a tab to watch live leads come in during the show.
